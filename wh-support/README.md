# Wh Support
## Service Desk для заявок
**Service Desk** – специализированное ПО, ориентированное на обработку специфических сервисных событий, поступающих в форме обращений пользователей или сообщений систем мониторинга. для последующего решения проблем и сбора аналитической информации.

### TicketApiProxyAdapter
Прокси-адаптер для сервиса TicketApi (набор endpoint-ов совпадает)

- *`POST`*: *`api/ticket/create`*: общая ручка для создания заявки (экшн - `CreateApplicationSD.Create`)

### TicketApi
API-сервис обработки запросов, связанных с заявками

- *`POST`*: *`api/ticket/create`*: общая ручка для создания заявки

### TelegramApproveBot
Telegram-бот, автоматически публикующий в чате информацию о заявках, созданных на сайте Wh-Support (https://support.wbwh.tech/).<br>
Бот отслеживает изменения статусов и обновляет сообщения при подтверждении, отклонении или выполнении заявки.
